What JSON files are used in RHYTHM?

                

                    Manifest file (manifest.json) — required when uploading DICOM archives. Describes the study, patient pseudo-ID, and acquisition metadata.

                    Anonymization config (anonymization_config.json) — used by the DICOM anonymization tool to define tag removal/replacement rules.

                    Use this validator to check both types before uploading or running the anonymizer.
