Automated Upload

Upload a batch of already-anonymised CT studies in one go: one ZIP archive per study, described by a manifest from the RHYTHM manifest tool. The server validates every archive and assigns each study its Repository Study ID.

View My Uploads

Before you start

You need four things ready.

  1. 1The manifest generator tool. Get the Windows .exe, the Python source and the instructions from github.com/jsfakian/rhythm/create_rhythm_service_manifest_gui_with_uid.
  2. 2The ID of the registered protocol for each study, copied from Protocol Records. The server derives region, indication, contrast, examination group and scanner from it, and checks that the manifest's site_code matches the protocol's site.
  3. 3One ZIP archive per anonymised CT study set, named exactly as in the manifest's items[].filename.
  4. 4Retention consent for each study: set retain_after_project to yes in the template if the patient authorised keeping the study after the project ends. Studies marked no or left empty are deleted at the end of the project.
